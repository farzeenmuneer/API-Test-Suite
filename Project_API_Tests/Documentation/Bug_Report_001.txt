BUG TITLE:
================================================================================
GET /users returns users without full name field - Only firstName and lastName

================================================================================
DESCRIPTION:
================================================================================
When sending a GET request to /users, the API returns users with 'firstName' 
and 'lastName' as separate fields instead of a single 'name' field. This could 
cause issues for applications expecting a full name field.

However, based on API documentation review, this is the intended behavior of
the DummyJSON API. The API provides firstName and lastName separately to allow
flexibility in how applications display user names.

================================================================================
STEPS TO REPRODUCE:
================================================================================
1. Send GET request to https://dummyjson.com/users
2. Observe the response structure
3. Note that 'name' field does not exist

================================================================================
EXPECTED RESULT:
================================================================================
API should return a 'name' field combining firstName and lastName.

================================================================================
ACTUAL RESULT:
================================================================================
API returns separate 'firstName' and 'lastName' fields.

================================================================================
ATTACHMENTS:
================================================================================
- 01_GET_Request_Working.png

================================================================================
COMMENTS:
================================================================================
This is NOT a bug. The DummyJSON API documentation confirms that firstName
and lastName are returned as separate fields by design.

Recommendation: Application developers should concatenate firstName and
lastName in the UI layer.
