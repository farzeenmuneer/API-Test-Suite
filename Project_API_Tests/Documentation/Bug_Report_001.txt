BUG TITLE:
================================================================================
GET /users returns users without full name field - Only firstName and lastName

================================================================================
DESCRIPTION:
================================================================================
When sending a GET request to /users, the API returns users with 'firstName' 
and 'lastName' as separate fields instead of a single 'name' field. This could 
cause issues for applications expecting a full name field.

================================================================================
STEPS TO REPRODUCE:
================================================================================
1. Send GET request to https://dummyjson.com/users
2. Observe the response structure
3. Note that 'name' field does not exist

================================================================================
EXPECTED RESULT:
================================================================================
API should return a 'name' field combining firstName and lastName.

================================================================================
ACTUAL RESULT:
================================================================================
API returns separate 'firstName' and 'lastName' fields.
