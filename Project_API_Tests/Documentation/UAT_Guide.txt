1. OBJECTIVE
================================================================================
The purpose of this User Acceptance Testing (UAT) guide is to validate that 
the User Management API is functionally stable, data-integrity compliant, 
and ready for production release.

This guide is designed for Business Stakeholders and Product Managers to 
independently verify that the API meets business requirements before 
production deployment.

================================================================================

================================================================================

Scenario 1: GET All Users
-------------------------------------------------------------------------------
Test Case ID:               UAT-001
Priority:                   HIGH

Objective: Verify the API returns a list of users successfully

Steps to Execute:
-------------------------------------------------------------------------------
1. Open Postman
2. Click "New" → "HTTP Request"
3. Method: GET
4. URL: https://dummyjson.com/users
5. Click "Send"
6. Observe the response

Expected Result:
-------------------------------------------------------------------------------
- Status code: 200 OK
- Response contains "users" array
- Each user has "id", "firstName", "lastName" fields

Scenario 2: POST Create User
-------------------------------------------------------------------------------
Test Case ID:               UAT-002
Priority:                   HIGH

Objective: Verify the API creates a new user successfully

Steps to Execute:
-------------------------------------------------------------------------------
1. Open Postman
2. Click "New" → "HTTP Request"
3. Method: POST
4. URL: https://dummyjson.com/users/add
5. Click "Body" tab → "raw" → "JSON"
6. Paste the following:
   {
       "firstName": "John",
       "lastName": "Doe"
   }
7. Click "Send"
8. Observe the response

Expected Result:
-------------------------------------------------------------------------------
- Status code: 201 Created
- Response contains "id" field
- Response contains "firstName": "John"
- Response contains "lastName": "Doe"
